# FraudOps Autopilot

FraudOps Autopilot is an AI-assisted fraud detection, investigation, and reviewer platform designed to empower fraud analysts with automated contextual risk scoring, multi-agent evidence synthesis, and interactive case management.

## Project Structure

```text
FraudOps-Autopilot/
├── documention/          # System design & architecture specifications
├── frontend/             # Member 3: React + TypeScript + Vite Reviewer Console
└── README.md             # Project documentation
```

## Team Work Division

- **Member 1**: Core Backend + Rule Engine
- **Member 2**: AI Agent Investigation System (LangGraph)
- **Member 3**: Frontend + Reviewer Experience (React + TypeScript + Vite)
- **Member 4**: Database + AWS Integration + QA
